Useful S3 attributes/features
Bucket name: Must be globally unique.
Region: Bucket is created in the AWS region configured in the provider.
Versioning: Keeps multiple versions of objects.
Encryption: Protects objects at rest.
Block Public Access: Helps prevent accidental public exposure.
Lifecycle rules: Automatically transition or expire objects.
Bucket policy: Controls access to the bucket and its objects.
Tags: Useful for organization, ownership, and cost allocation.
